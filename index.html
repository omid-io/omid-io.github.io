antigravity-pause v0.1.0-stable

Graceful Pause, Deep Hibernation & Pre-Flight Leak Protection for Google Antigravity (2.0 Desktop, IDE, and CLI). Shields sessions against 403 Forbidden geoblocks, ECONNRESET socket drops, and stuck Git index locks.

GitHub Repo
✓ <200ms Pre-Flight Leak Probe: Blocks requests before an IP leak causes API gateway session bans.
✓ Zero-Kill Hot Standby (/pause): Suspends subagent trees into radio silence without killing process memory.
✓ Atomic Checkpointing (/hibernate): Safely dumps multi-turn context and subagent tasks to disk snapshots.
✓ Git Lock Sanitizer: Automatically detects and removes orphaned .git/index.lock files. 
# 1. Hot Standby during VPN switches
/pause      # Enters radio silence; holds HTTP/2 sockets safely
/play       # Validates non-sanctioned exit node in <140ms & resumes

# 2. Deep Hibernation for system reboot / shutdowns
/hibernate  # Atomic state snapshot dumped to .checkpoints/
/continue   # Rehydrates state and continues next task step
