Graceful Pause, Deep Hibernation & Pre-Flight Leak Protection for Google Antigravity (2.0 Desktop, IDE, and CLI). Shields sessions against 403 Forbidden geoblocks, ECONNRESET drops, and stuck Git index locks.

GitHub Repo
✓ <200ms Pre-Flight Leak Probe: Blocks requests before an IP leak can cause a 403 sanction ban.
✓ Zero-Kill Hot Standby (/pause): Suspends subagent trees into light sleep without terminating processes.
✓ Atomic Checkpointing (/hibernate): Safely dumps multi-turn context and subagent tasks to disk.
✓ Git Lock Sanitizer: Automatically detects and removes orphaned .git/index.lock files.
